# Eye-vs-Face Project Repository

This repository contains the analysis code, model training, and figure-generation notebooks for the manuscript.

The project is organized into reusable analysis code, figure notebooks, and generated outputs.

---

# Repository Structure

```
.
├── data/                  # Raw and intermediate data files
├── paper/                 # Notebook and helper functions for generating paper figures
├── analysis/
│   ├── code/              # Reusable analysis code
│   └── notebooks/         # Analysis notebooks
├── figures/               # Generated figures
├── images/                # Static images used in figures
├── conda_packages_list.txt
└── README.md
```

---

# Directory Details

## `data/`

Contains pre-processed data and intermediate processed files required for analysis.

Large files not tracked in Git so this folder needs to be downloaded from figshare.

---

## `paper/`

Contains figures.ipynb notebook used to generate all the figures for the manuscript.

---

## `analysis/code/`

Reusable Python modules used throughout the project:

* `get_keypoints_psth.py` — Keypoints alignment to saccade events for fig3 
* `get_saccades.py` — Saccade compilation using entire dataset and saccade-related outputs
* `get_running_psth.py` — Running-related analyses for fig3
* `nonlinear_modelv3.py` — Model definitions and training
* `helper_functions.py` — General utilities
* `pupil_dark_helpers*.py` — Preprocessing utilities
* `loaders.py` — Data loading functions

These files are imported by the notebooks except for `get_keypoints_psth.py`, `get_saccades.py` and `get_running_psth.py` which have to be run independently by calling `python filename`.

---

## `analysis/notebooks/`

Jupyter notebooks used for data processing, model training, evaluation, and all analyses:

* `generate_svds.ipynb`
* `geom_to_deg_saccade.ipynb`
* `run_predictions.ipynb`
* `tuning_curves.ipynb`
* `keypoints_prediction.ipynb`
* `saccade_video.ipynb`
* `UnEye.ipynb`

---

## `figures/`

Contains exported figure panels generated by the notebook in the paper folder.

---

## `images/`

Static images used in the manuscript figures.

---

# Environment Setup

It is recommended to use a Conda environment.

To reproduce the environment:

```bash
conda env create -f environment.yml
conda activate eye_vs_face
```

---

# Recommended Execution Order

If regenerating all processed data and figures:

1. `generate_svds.ipynb`
2. `geom_to_deg_saccade.ipynb`
3. `run_predictions.ipynb`
4. `tuning_curves.ipynb`
5. `keypoints_prediction.ipynb`
6. `saccade_video.ipynb`

Run notebooks from top to bottom without skipping cells.

---

# Reproducibility Notes

* Ensure file paths are correct relative to the repository root.
* Some notebooks depend on outputs generated by earlier notebooks.
* Random seeds should be fixed where applicable for exact replication.
* Large datasets may need to be obtained separately from figshare.
